Create a [Holon](https://github.com/holon-sh/cli) app with a Python server:

```sh
uvx create-holon-app orders
```

This runs `holon init --lang py` from [holon-types](https://pypi.org/project/holon-types/), which installs the `holon` CLI for your platform. See the [CLI README](https://github.com/holon-sh/cli#create-an-app) for what it creates.
