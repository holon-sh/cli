Create a [Holon](https://github.com/holon-sh/cli) app:

```sh
npm create holon-app@next orders -- --lang ts
```

This runs `holon init` from [holon-types](https://www.npmjs.com/package/holon-types), which installs the `holon` CLI for your platform. See the [CLI README](https://github.com/holon-sh/cli#create-an-app) for what it creates.
