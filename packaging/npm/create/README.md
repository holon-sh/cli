Create a [Holon](https://github.com/holon-sh/cli) app with a TypeScript server:

```sh
npm create holon-app orders
```

This runs `holon init --lang ts` from [holon-types](https://www.npmjs.com/package/holon-types), which installs the `holon` CLI for your platform. See the [CLI README](https://github.com/holon-sh/cli#create-an-app) for what it creates.
